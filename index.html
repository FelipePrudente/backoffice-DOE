Cache e performance
  • Os dados ficam no Neon (Postgres). Use npm run bg:install para API + worker sem terminal (início no logon).
  • O worker faz a carga inicial (5 dias), complementa a cada 60 segundos e reconcilia o dia a cada 3 minutos. Matérias com created_at com mais de 10 dias são excluídas automaticamente.
  • Pesquisar / Atualizar consultam o Neon (rápido). O worker mantém a base alinhada com a API DOE.
  • isImmediate=true = Imediata · createdAt = entrada · schedule = Data Prevista.
  • Buscar procura em título, seção, publicante, CPF, autenticação, identificação e caderno/seção. Os filtros específicos continuam disponíveis em Customizar filtros.
